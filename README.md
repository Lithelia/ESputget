## <概要>

Ver.01をすでにご利用中の場合、Ver.02のファイルですべて置き換えてください。

Windows PCからESERAMairとの送受信を行うための、PowerShellスクリプトとバッチを作成しました。<BR>
バッチファイルの中にあるファイル名部分を書き換えて利用ください。<BR>
これらのバッチを活用することで、PC側でのコンパイルやアセンブル→MSXへの送信、を繰り返したい場合などに、ダブルクリックだけで済むようになります。

ESERAMairのpico部分が起動していれば使えますので、MSXに挿して使うのはもちろん、MSXに挿さずにUSBで電源を供給するだけでも使えます。<BR>
同一サブネット外から利用する場合は、PowerShellスクリプトの「eseram.local」部分をIPアドレスに書き換えてください。

## <免責>

本スクリプトは、利便性向上のために上書きや初期化の確認が行われません。このため、操作の誤りにより、ファイルが消失する恐れがあります。
また、バグによって想定通りの動作とならないことや、ファイルが消失する可能性もあります。作者は消失したファイルを復元することはできません。<BR>
これらをご理解の上、十分注意してお使いください。

## <説明>

## 1. ESERAM diskとして初期化する

***putnextor.bat***

nextor-eseramair.romをアップロードして、SRAMのフォーマットを行います。
これにより、ESERAM Diskとして使用できるようになります。
スクリプトと同じフォルダに、nextor-eseramair.romを置いておく必要があります。

## 2. ESERAM diskを中のファイル単位で利用する

これらのコマンドはESERAM Diskとして利用できるようにしておく必要があります。「putnextor.bat」を先に実行しておいてください。

***put1.bat***

指定のファイルをESERAMairに送信します。
2行目最後の「SF.COM」部分を任意のファイルに置き換えてください。
PC側のタイムスタンプもMSX側で維持されます。

***get1.bat***

指定のファイルをESERAMairから受信します。
2行目最後の「SF.COM」部分を任意のファイルに置き換えてください。
こちらはタイムスタンプは受信日時になります。
（タイムスタンプを維持するように、追加実装予定）

***dir1.bat***

ESERAMairのステータスとファイル一覧を表示します。

## 3.ESERAM diskをディスクイメージとして利用する

これらのコマンドはESERAM Diskとして利用できるようにしておく必要があります。「putnextor.bat」を先に実行しておいてください。

***putimage1.bat***

指定のファイルをESERAMairにFATイメージとして送信します。
2行目最後の「fatimage.bin」部分を任意のファイルに置き換えてください。<BR>
ファイルサイズ分のデータが送信されるため、putではimageとdiskは同じ動作になります。

***putdisk1.bat***

指定のファイルをESERAMairにFATイメージとして送信します。
2行目最後の「image.dsk」部分を任意のファイルに置き換えてください。<BR>
ファイルサイズ分のデータが送信されるため、putではimageとdiskは同じ動作になります。

***getimage1.bat***

ESERAMairからFATイメージとして896KBのデータを受信し、指定のファイルとして書き出します。
2行目最後の「fatimage.bin」部分を任意のファイルに置き換えてください。

***getdisk1.bat***

ESERAMairからFATイメージとして720KB（2DDのイメージサイズ)のデータを受信し、指定のファイルとして書き出します。
2行目最後の「image.dsk」部分を任意のファイルに置き換えてください。<BR>
この機能は、putdisk1.batで720KBのディスクイメージをアップロードした後で利用してください。
ESERAMairの機能でフォーマットした場合は896KBのディスクになるため、176KBの取得漏れが起こります。


## 4.メガロムとして利用する場合や、全体のバックアップ／リストア

***putrom1.bat***

ESERAMairに指定のROMイメージファイルを送信します。書き込み先は先頭からになります。メガロムの書き込みや全体イメージのリストアなどに使用します。<BR>
2行目最後の「IMAGE.ROM」部分を任意のファイルに置き換えてください。

***getrom1.bat***

ESERAMairのすべてのデータ1024KB(8MBit)を受信し、指定のファイルとして書き出します。
書き込まれているメガロムの読み込みや、全体イメージのバックアップに使用しますが、実際に使用されているサイズはわからないため、全データを取得します。<BR>
2行目最後の「IMAGE.ROM」部分を任意のファイルに置き換えてください。

## 5.共通PowerShellスクリプト

***ESput.ps1***

ファイル送信用のPowerShellスクリプトです。

***ESget.ps1***

ファイル一覧及びファイル受信用のPowerShellスクリプトです。
