**概要**

ESERAMairで送受信を行うためのPowershellスクリプトとバッチを作成しました。
バッチファイルの中にあるファイル名部分を書き換えて利用ください。
これにより、PC側でのコンパイルやアセンブル→MSXへの送信、を繰り返したい場合などに、ダブルクリックだけで済むようになります。

ESERAMairのpico部分が起動していれば使えますので、MSXに挿して使うのはもちろん、MSXに挿さずにUSBで電源を供給するだけでも使えます。
同一サブネット外から利用する場合は、Powershellスクリプトの「eseram.local」部分をIPアドレスに書き換えてください。

**put1.bat**

指定のファイルをESERAMairに送信します。
2行目最後の「SF.COM」部分を任意のファイルに置き換えてください。
PC側のタイムスタンプもMSX側で維持されます。

**get1.bat**

指定のファイルをESERAMairから受信します。
2行目最後の「SF.COM」部分を任意のファイルに置き換えてください。
こちらはタイムスタンプは受信日時になります。
（タイムスタンプを維持するように、追加実装予定）

**dir1.bat**

ESERAMairのステータスとファイル一覧を表示します。


**ESput.ps1**

ファイル送信用のPowershellスクリプトです。

**ESget.ps1**

ファイル一覧及びファイル受信用のPowershellスクリプトです。
